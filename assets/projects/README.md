# Portfolio Project Images

This directory contains the images for the portfolio gallery. To properly set up the portfolio with the images from Google Drive, follow these instructions:

## Directory Structure

The portfolio is organized into 7 projects, each with 4 images:

```
assets/projects/
├── project1/
│   ├── image1.jpg
│   ├── image2.jpg
│   ├── image3.jpg
│   └── image4.jpg
├── project2/
│   ├── image1.jpg
│   ├── image2.jpg
│   ├── image3.jpg
│   └── image4.jpg
...and so on for projects 3-7
```

## Instructions for Adding Images

1. Download all images from the Google Drive folder: https://drive.google.com/drive/folders/1zvDC5f3Vz_q0relEH8umjrYT1MlKmJj8

2. Create the project directories if they don't exist already:
   ```
   mkdir -p project1 project2 project3 project4 project5 project6 project7
   ```

3. Organize the images into the appropriate project folders:
   - For each project, select 4 related images
   - Rename them to image1.jpg, image2.jpg, image3.jpg, and image4.jpg
   - Place them in the corresponding project folder

4. The first image (image1.jpg) will be used as the main thumbnail for each project

## Project Organization

The portfolio is organized into three sections:

1. **Residential Projects** (projects 1-3)
   - Project 1: Contemporary Residence
   - Project 2: Luxury Waterfront Villa
   - Project 3: Urban Living Complex

2. **Commercial Projects** (projects 4-5)
   - Project 4: Corporate Headquarters
   - Project 5: Mixed-Use Development

3. **Public & Institutional** (projects 6-7)
   - Project 6: Cultural Center
   - Project 7: Educational Campus

Choose images that best represent each project type when organizing them into folders.
